# Mona Khaled — portfolio (static)

Single-page portfolio for GitHub Pages.

## Publish on GitHub

1. Create a new repository on GitHub (for example `portfolio` or `mona-portfolio`).
2. Upload the contents of this folder so that **`index.html` is at the repository root** (same level as this README).
3. On GitHub: **Settings → Pages → Build and deployment → Source**: choose **Deploy from a branch**.
4. Set **Branch** to `main` (or `master`) and folder **`/ (root)`**, then save.
5. After a minute, the site will be live (this repo): **https://mona690.github.io/mona-portfolio/**

### Custom domain (optional)

Use **Settings → Pages → Custom domain** and follow GitHub’s DNS instructions.

## Local preview

Open `index.html` in your browser, or run a small static server from this folder, for example:

```bash
npx --yes serve .
```

## Content

All work samples live under a single **Projects** heading in `index.html`. Add buttons/links for POS, ERP, or Cooking Up Good Speech when you have public URLs.
